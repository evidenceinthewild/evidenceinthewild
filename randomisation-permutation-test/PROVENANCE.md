# Provenance and inferential scope

Last reviewed: 19 August 2026

## Bottom line

The repository contains a constructed patient-level dataset, not the original Study 201 individual patient data. Some baseline quantities are reported directly, some arm-level quantities are read approximately from figures, and the remaining individual values are reconstruction choices. The exact enumeration is exact only conditional on those inputs and the assumed assignment set.

## What is and is not identified by the publications

The published group information identifies selected summaries, including arm sizes and baseline summaries. It does not identify the full Week 24 patient-level outcome vector. A raw-mean permutation distribution depends on that full vector, so the publications do not identify a unique permutation p-value.

For the displayed constructed vector, the code enumerates all 70 four-versus-four allocations and returns p = 0.029. Across 1,000 generated configurations preserving the chosen group-mean targets, the median is 0.086 and 25% fall below 0.05. Because balanced 4-v-4 two-sided p-values move in steps of 2/70, that 25% is exactly the proportion at the floor of 2/70; no values between 0.0286 and 0.0571 exist. These percentages describe this repository's ad hoc generator, not a probability distribution for the missing patient data.

## Design qualifications

The pairwise test conditions on the eight participants assigned to 50 mg/kg or placebo and treats all four-of-eight reallocations as available. Calling it a randomisation test generated by the actual design requires confirmation that this reference set respects any restrictions used in the original allocation, such as blocks or strata.

The test uses a sharp null of no individual treatment effect and a raw difference in means at Week 24. It does not reproduce the published longitudinal MMRM estimand. The two p-values therefore cannot be interpreted as interchangeable answers to the same question.

The mITT test explicitly excludes patient IDs 009 and 010 because they lost ambulation after randomisation. Permuting outcomes only within the selected set is not automatically protected by the original randomisation. The p = 0.005 result should remain exploratory unless a selection-aware randomisation procedure is justified.

## Source-detail work still required

Before describing any reconstructed group target as published, add the exact document, page or slide, extraction method, and rounding rule. In particular:

1. identify a page-level source for the 50 mg/kg raw Week 24 mean of +12.5 m, or label it permanently as an analysis assumption;
2. identify every value taken from the FDA Clinical Review, NDA 206488, which is cited by the code but not mapped to a page;
3. preserve separate provenance for baseline, Week 24 value, and change; and
4. document or implement the integer-solution search before claiming a reconstruction is unique.
