# The Permutation Test Nobody Ran

Exact permutation tests for Study 201 (NCT01396239), the pivotal eteplirsen trial in Duchenne muscular dystrophy. Companion analysis to [Randomisation in the Wild Part 4](https://evidenceinthewild.com/randomisation-permutation-test/).

## What this is

Mendell et al. (2013) randomised 12 boys to three arms (30 mg/kg, 50 mg/kg, placebo) and analysed the six-minute walk test (6MWT) using a mixed model for repeated measures (MMRM). The MMRM found no significant difference for 50 mg/kg vs placebo at Week 24 (approximate two-sided p ≈ 0.56, derived from published adjusted means and standard errors).

This repository runs the exact permutation test that Fisher's randomisation-based framework prescribes for a trial of this size. The two-sided permutation p-value for the same comparison is 0.029. Details and interpretation are in the [blog post](https://evidenceinthewild.com/randomisation-permutation-test/).

## Important: reconstructed data

**The patient-level data in this repository are not original clinical data.** Individual 6MWT values were never published in tabular form. The values in `data/reconstructed_patient_data.csv` are reconstructed from published summary statistics (group means, standard deviations, minimums, and maximums from Table 1 and Figure 6 of Mendell et al. 2013). Two patients' baselines are stated in the paper text; the remainder are algebraically determined. See the `source` column in the CSV for full provenance.

The sensitivity analysis (`code/sensitivity_analysis.py`) tests whether the permutation result is robust across alternative plausible individual patient allocations that preserve the published group means.

## Reproducing the results

```bash
pip install -r code/requirements.txt
python code/eteplirsen_permutation_analysis.py   # main analysis → results/
python code/sensitivity_analysis.py              # robustness check → results/
python code/create_visualizations.py             # figures → figures/png/, figures/pdf/
```

Scripts must be run in order. The analysis script produces `.npy` and `.json` files that the other two scripts read. Python 3.8+ required.

## Key results

| Comparison | Observed difference | Permutation p (two-sided) | MMRM p |
|---|---|---|---|
| 50 mg/kg vs placebo | +67.5m | 0.029 | ≈ 0.56 (derived) |
| mITT eteplirsen (n=6) vs placebo | +70.0m | 0.005 | -- |
| All eteplirsen (ITT) vs placebo | +2.9m | 0.97 | -- |

The sensitivity analysis shows the mITT result is robust (90% of plausible allocations yield two-sided p < 0.05). The dose-arm result is suggestive (25% below p < 0.05; 67% below p < 0.10).
